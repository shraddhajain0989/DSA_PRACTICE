---------------------------------
In many coding questions/interviews:

❌ Collections.sort()

❌ sorted()

are NOT allowed.

Because interviewer wants to check:
1) Logic

3) Time Complexity Understanding


=================================
MAIN 3 APPROACHES
=================================

1) BRUTE FORCE
2) USING SWAP METHOD
3) OPTIMIZED / BETTER TIME COMPLEXITY


=================================
1) BRUTE FORCE METHOD
=================================

Meaning:
--------
Solve problem in simplest/basic way.

Mostly uses:
- Nested loops
- Checking every element

Advantages:
-----------
✅ Easy to understand
✅ Easy to write

Disadvantages:
--------------
❌ Slow for large input
❌ More time complexity

Common Time Complexity:
-----------------------
O(n²)
O(n³)

Example:
--------
Find largest element in array

Code:
-----

int max = arr[0];

for(int i = 0; i < arr.length; i++){

    if(arr[i] > max){
        max = arr[i];
    }
}

Time Complexity:
----------------
O(n)



=================================
2) USING SWAP METHOD
=================================

Meaning:
--------
Swap elements to place them correctly.

Used in:
--------
- Bubble Sort
- Selection Sort
- Cyclic Sort
- Two Pointer Problems

SWAP FORMULA:
-------------

int temp = arr[i];
arr[i] = arr[j];
arr[j] = temp;


=================================
BUBBLE SORT
=================================

Concept:
--------
Largest element moves to end after every round.

Example:
--------

5 4 3 2 1

Round 1:
4 3 2 1 5

Round 2:
3 2 1 4 5

Round 3:
2 1 3 4 5

Round 4:
1 2 3 4 5


Code:
-----

for(int i = 0; i < arr.length; i++){

    for(int j = 0; j < arr.length - 1 - i; j++){

        if(arr[j] > arr[j+1]){

            int temp = arr[j];
            arr[j] = arr[j+1];
            arr[j+1] = temp;
        }
    }
}


IMPORTANT:
----------
arr.length - 1 - i

Because last elements are already sorted.


Time Complexity:
----------------
O(n²)



=================================
SELECTION SORT
=================================

Concept:
--------
Find minimum element and swap.

Code:
-----

for(int i = 0; i < arr.length; i++){

    int minIndex = i;

    for(int j = i + 1; j < arr.length; j++){

        if(arr[j] < arr[minIndex]){
            minIndex = j;
        }
    }

    int temp = arr[i];
    arr[i] = arr[minIndex];
    arr[minIndex] = temp;
}


Time Complexity:
----------------
O(n²)



=================================
INSERTION SORT
=================================

Concept:
--------
Place element at correct position.

Code:
-----

for(int i = 1; i < arr.length; i++){

    int current = arr[i];
    int j = i - 1;

    while(j >= 0 && arr[j] > current){

        arr[j + 1] = arr[j];
        j--;
    }

    arr[j + 1] = current;
}


Time Complexity:
----------------
O(n²)



=================================
3) OPTIMIZED METHOD
=================================

Meaning:
--------
Solve problem in faster way.

Goal:
-----
✅ Reduce loops
✅ Reduce unnecessary work
✅ Improve time complexity


=================================
TIME COMPLEXITY
=================================

O(1)       -> Best
O(log n)   -> Very Fast
O(n)       -> Good
O(n log n) -> Best for sorting
O(n²)      -> Slow
O(2ⁿ)      -> Very Slow

-----------------

-----------------

Time:
O(n²)


4) Merge Sort
-------------

Divide and merge

Time:
O(n log n)

-------------

Pivot partition

Time:
O(n log n)
